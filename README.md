**Blast Round – HTML5 Block Puzzle RPG Game (Vanilla JS)**

Blast Round is a complete, production-ready HTML5 puzzle game that takes the classic block-clearing mechanics of games like Block Blast or 1010! and upgrades them with gravity cascades, spellcasting, and boss fights.

The game is written in pure Vanilla JavaScript (HTML5 / CSS3) with zero external dependencies, frameworks, or engines. It runs at a locked 60 FPS, loads instantly, and is completely ready to deploy on web portals, package into an mobile app, or customize for your own projects.

**🎮 Gameplay & Core Features**

Cascade Gravity Physics: Clearing lines causes remaining blocks above to drop down under gravity, triggering chain-reaction combos for extra points.

RPG Boss & Mana Mechanics: Players build mana by clearing lines, unlocking special spells to deal with tough grid situations and defeat stage bosses.

Special Grid Blocks: Features multi-hit Ice blocks, TNT explosives (3x3 area destruction), and countdown Bomb traps to keep gameplay strategic.

Power-Up Shop: Integrated coin economy where players can buy game-altering power-ups like the Hammer or Shuffle.

Cosmetics & Theme Unlocks: Color themes and visual skins unlocked through progression or coin purchases.

**⚡ Technical Highlights**

100% Pure Vanilla JS: No Phaser, no React, no build steps required. Clean, modular code that is easy to read, edit, and maintain.

Procedural Web Audio API: Sound effects (explosions, line clears, UI clicks) are synthesized dynamically in JavaScript. No external .mp3 or .wav audio files to load.

Touch & Mobile Optimized: Uses native Pointer Events with proper touch-handling, preventing page scrolling issues on iOS and Android.

Local Storage Auto-Save: Player stats, high scores, coin balance, and active games save automatically.

Ultra Lightweight: Minimal file size ensures instant loading even on slow mobile networks.
